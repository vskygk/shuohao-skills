# Production Bible Review Checklist

Use this before production or after a substantial revision.

- Every rule is scoped to the project, a scene, a character group, or a delivery target.
- Rules are observable: a reviewer can determine whether an image, shot, or prompt followed them.
- Character identity groups list immutable features separately from allowed changes.
- Scenes with consequential movement explain how a character enters, exits, ascends, descends, or crosses a boundary.
- State-changing props and spaces define their before/after states.
- Reference-video prompts map every keyframe to its intended shot and time.
- Audio references say whether they guide timbre or reuse the source signal; upload order is not embedded in the model prompt body.
- Image replacement names every derived report, manifest, prompt package, or index that must be rebuilt.
- Git policy distinguishes reviewed source assets from temporary generations, revisions, and exports.
